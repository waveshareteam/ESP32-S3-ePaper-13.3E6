# Waveshare ESP32-S3-ePaper-13.3E6

[中文](README_ZH.md)

The ESP32-S3-ePaper-13.3E6 is a development board designed for a 13.3-inch, 1600 × 1200 six-color e-Paper display. Built around the ESP32-S3 with 2.4 GHz Wi-Fi and Bluetooth 5 LE, it integrates audio, RTC, TF card, USB Type-C, and battery-related functions, making it suitable for wireless picture frames, information boards, smart displays, and other low-power IoT applications.

## Repository Structure

This repository provides sample programs, factory firmware, and SD card resources for the ESP32-S3-ePaper-13.3E6.

```text
.
├── example/         # Sample programs for ESP-IDF and Arduino
├── Firmware/        # Factory firmware (.bin)
├── SD_files/        # SD card images, audio, and web resources
└── assets/          # Images used in documentation
```

## Getting Started

A pre-built factory firmware is available in [`Firmware/`](Firmware), and the required SD card resources are available in [`SD_files/`](SD_files). For development environment setup, flashing steps, pin mappings, and configuration details, refer to the [documentation page](https://docs.waveshare.com/ESP32-S3-ePaper-13.3E6).
